# Frontend Development Project

Responsive personal portfolio demonstrating HTML structure, CSS styling, Flexbox/Grid layout, and JavaScript interactions.

## Features
- Responsive hero, about, projects, skills and contact sections
- CSS Grid and Flexbox layouts with mobile breakpoints
- Mobile navigation toggle
- Contact form validation and email-draft generation
- Accessible labels and status messages

## Run
No build tools are required. Open `index.html` in a browser, or use VS Code Live Server.

## Customize before publishing
Replace the sample biography and project descriptions with your own work. Change `hello@example.com` in `script.js` to the email address you want to use. The form opens an email draft; it does not send or store submissions by itself.
